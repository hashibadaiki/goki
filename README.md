# GOKI

ゴキブリになって深夜のキッチンを這い回る、一人称視点のブラウザゲームです。

遊ぶ: https://goki.hashiba-baan-daiki.workers.dev

パンくずを 8 個集めて、冷蔵庫の下の巣へ帰れば勝ちです。床も壁も天井も歩けます。ときどき電気がつき、人間が巡回に来ます。視線に入ると発見ゲージが溜まり、満タンになるとスリッパや殺虫剤が飛んできます。

## 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | 画面左をドラッグ |
| 視点 | マウス（クリックでカーソルを固定） | 画面右をドラッグ |
| 走る | Shift | スティックを端まで倒す |
| 跳ぶ | Space | 「跳ぶ」ボタン |
| 羽ばたき | 空中で Space 長押し | 空中で「跳ぶ」長押し |
| 一時停止 | Esc | 右上の II |

## 遊び方のコツ

- 消灯中は人間がいません。この間に遠くのパンくずを取りに行きます
- 足音が聞こえたら、テーブルの下、戸棚の天板の裏、冷蔵庫の下など、真上から見えない場所に隠れます
- 走ったり近くで動いたりすると、発見ゲージが速く溜まります
- スリッパは影が落ちてから 0.75 秒後に振り下ろされます。影が見えたら横へ走って逃げます

## 開発

```sh
pnpm install
pnpm dev
```

ビルドすると `dist/` に静的ファイルが出力されます。

```sh
pnpm build
pnpm preview
```

## デプロイ

Cloudflare Workers に静的アセットとして配信します。cf CLI を使います。

```sh
cf auth whoami
pnpm run deploy
```

## 技術メモ

- Three.js と TypeScript、Vite で作っています
- ゴキブリの移動は、レイキャストで足元の面と進行方向の面を調べ、面の法線に合わせて上方向を回して実現しています。凹んだ角では前方の面に乗り移り、出っ張った角では元の面の側面に回り込みます
- キッチンの静的な形状は頂点カラー付きの箱をまとめて 1 つのメッシュにしているので、描画命令が少なく済みます
- スマホは起動時に判定して、影やアンチエイリアスを切り、ピクセル比を 1.5 までに抑えます
- 1 フレームにかかる時間を測り、重ければ描画解像度を下げ、余裕があれば戻します
- 影は 1 フレームおきにだけ更新します
- 効果音はすべて Web Audio で合成しているので、音声ファイルはありません
